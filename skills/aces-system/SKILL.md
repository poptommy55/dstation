## 🔴🔴 生成物必须落盘到工作区（2026-09-13 新增，最高优先级）

**这是"生成成功"与"用户能看见"之间的唯一一环，漏掉它用户就会报「AI 生成图片不会自动显示」。**

**为什么会这样**：本 skill 的创作接口只返回**远端结果**——`taskId` + query 响应里的
`results[].url`（对象存储链接）。全程**没有任何本地文件**。而宿主环境的「媒体预览」能力
识别的是**正文里的绝对文件路径**，所以远端链接默认不会变成可预览、可下载的卡片。

**因此：任何生成类任务（文生图/图生图/图生视频/背景音乐/数字人）判定成功后，必须按顺序做三步。**

**第 0 步（必做，只需一秒）：确认落盘目录在工作区内。**

宿主调用脚本时，**python 的工作目录就是当前会话工作区**，所以不要手写路径——
直接让它算，并看一眼打印结果对不对：

```bash
# 直接自检：会打印 resolve_out_dir() 的结果
python aces_save.py
```

- 输出里若包含 `aces-output` 且前缀是你的会话工作区 → 正常，继续。
- 若它指向**技能目录**（如 `…\skills\aces-system\aces-output`）→ 说明工作目录不对，
  必须显式传 `out_dir=<会话工作区绝对路径>` 覆盖，否则落盘后无法预览。

```python
import aces_save

r = c.submit_and_wait(...)                     # ① 等终态
if r["status"] == "SUCCESS":
    saved = aces_save.save_outputs(             # ② 落盘（默认即 <工作区>/aces-output）
        r.get("result"),
        prefix="aces_描述_比例_分辨率",          # 例：aces_橘猫窗台_16x9_2k
    )
    aces_save.print_paths(saved)                # ③ 打印绝对路径
```

**硬性要求：**

1. **落盘目录必须在当前会话工作区之内**。默认值已经是 `<python cwd>/aces-output`，
   而 DSH 下 cwd 就是工作区；**只有在自检发现它指到技能目录时**才需要显式传 `out_dir`。
   落到工作区外 = 预览与下载都取不到 = 用户会报"生成成功但看不到图"。
2. **落盘成功后，回复正文里必须出现这些文件的绝对路径**（原样、单独成行最好）。
   预览卡片锚定在正文路径上——路径不写出来，等于没落盘。
3. **提交任务后立刻把 taskId 落盘**（例如写进 `<工作区>/aces-output/_last_task_id.txt`）：
   进程若被中断，还能用『查 ACES 任务 <id>』把结果接回来。
   ACES 没有任务列表接口，只支持按 taskId 查——丢了 id 就等于白烧一次额度（实测吃过这个亏）。
4. **落盘失败要如实说明**（含失败原因与远端链接），不要只说"生成成功"，让用户干等一张永远不出现的图。
5. 若用户明确说"只要链接不用存"，可以不落盘，但要**主动说明"这样不会出现预览卡片"**，由用户决定。

## 🔴 消耗与额度通报（生成成功后必须）

**核心认知（务必记牢）：ACES 系统是「按次计」的账户配额，不是「按元计费」。**

- 用户每个 KEY 账户有独立的额度：`今日剩余 / 每日额度 / 累计已用 / 总限额`（次数）。
- 这与 ACES 网页导航栏「今日剩余 N / 每日额度 M」同源。

**通报规则（生成成功后）：**
1. 调用 `submit_and_wait()` 成功时，返回 dict 已自动附带 `quota` 字段（来自 `get_quota()`）。若未自动附带，显式调用 `c.get_quota()`。
2. 用 `ACESClient.format_quota_report(quota)` 生成中文通报行，作为**唯一主通报**：
   > 生成成功 ✅ ｜ 本次消耗：1 次（ACES 账户额度）｜ <format_quota_report 结果>
3. **绝不主动提起任何金额、费用、扣费、成本等数值**；如果用户追问计费方式，统一回答「ACES 按账户额度（次数）计费，不涉及金额」。

调用示例：
```python
r = c.submit_and_wait(...)
if r["status"] == "SUCCESS":
    print("生成成功 ✅ ｜ 本次消耗：1 次（ACES 账户额度）｜", ACESClient.format_quota_report(r.get("quota")))
```
